# StalkLab — Ghost Face Strategy Lab

Dead by Daylight の**ゴーストフェイス専用**攻略ラボ。マップごとの覗きスポット・立ち回り・パーク/アドオン構成を登録、検索できる Web アプリです(v0.2 シングルユーザー版)。

> キャッチコピー: ゴスフェ使いが、ゴスフェ使いのために作った攻略ラボ

## 機能(v0.2)

- **パーク構成**: 4パーク+2アドオン+タグ+コンセプト+得意/苦手マップ+相手対策メモを登録・編集・削除。タグ/キーワード検索、いいね順・使ってみた順ソート
- **マップ & 覗きスポット**: Realm別マップ一覧 → レイアウト図(簡易プレースホルダー)をクリックしてピン留め(x/y座標)。利点・注意点・タグ付き。マップの追加も可能
- **立ち回りノート**: マップ別×フェーズタグ(初動/中盤/終盤など)のメモ
- **バックアップ**: JSONエクスポート/インポート

データはブラウザの localStorage に保存されます(サーバー不要)。

## 設計方針

データ構造は要件定義書の Firestore スキーマ(`perkBuilds` / `stalkSpots` / `strategyNotes` / `maps`)と同一フィールド名にしてあり、将来 Firebase Auth + Firestore に移行する際は保存層(`src/App.jsx` の `load`/`save`)のみ差し替えれば移行できます。

## 動かし方

Node.js 20 以上が必要です。

```bash
npm install
npm run dev
```
